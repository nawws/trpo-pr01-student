# Практическая работа №1 — HTML и базовая CSS-разметка

Многораздельная адаптивная информационная страница курса «Технологии разработки программного обеспечения» на чистых HTML и CSS (без JavaScript и фреймворков). Содержимое построено по данным из `dataset`.

## Запуск

1. Клонировать репозиторий: `git clone <url> && cd trpo-pr01-student`
2. Открыть `index.html` в браузере (двойной клик).
   Или через локальный сервер: `python -m http.server 8000` → http://localhost:8000

Все пути относительные, проект работает после переноса папки в любое место.

## Структура проекта

```
index.html          — страница
css/styles.css      — стили
images/             — logo.svg, cover.svg (из dataset/assets)
data/               — content.csv, navigation.json (копии из dataset)
dataset/            — исходные файлы задания без изменений
```

## Использование dataset

| Файл | Где используется |
|---|---|
| `navigation.json` | Пункты меню в `<nav>`: `label` → текст ссылки, `target` → `href="#target"` и `id` раздела (`about`, `tracks`, `schedule`, `signup`) |
| `content.csv` | 6 карточек раздела «Направления» (`title`, `category`, `description`, `value`), `id` → `id="track-N"`; таблица «Расписание»; варианты `<select>` в форме |
| `assets/logo.svg` | Логотип в шапке (декоративный, `alt=""`) |
| `assets/cover.svg` | Обложка в разделе «О курсе» (с содержательным `alt`) |

Маршрут данных: CSV/JSON → значения перенесены вручную в разметку `index.html` (допускается на первом этапе) → оформление классами из `styles.css`.

## Структура HTML

- `header.site-header` → логотип + `nav[aria-label]` со списком ссылок
- `main#main`:
  - `section#about` — заголовок `h1`, описание, `figure` с обложкой
  - `section#tracks` — список `ul.cards`, каждая карточка — `article.card` с `h3`
  - `section#schedule` — `table` с `caption`, `thead`, `tbody`, `tfoot` (текстовые и числовые столбцы, итог)
  - `section#signup` — форма регистрации
- `footer.site-footer`

Иерархия заголовков: `h1` → `h2` (разделы) → `h3` (карточки).

## Форма

`label` для каждого поля; типы `text`, `email`, `number`, `range`, `radio`, `checkbox`, `select`, `textarea`.
Ограничения: `required`, `minlength="3"`/`maxlength="80"` (ФИО), `maxlength="500"` (текст), `pattern` (группа), числовое `min="1" max="6"` (курс).

**Ошибочное состояние:** при пустом или неверном вводе браузер блокирует отправку и показывает сообщение; через `:user-invalid` поле подсвечивается красным только после взаимодействия пользователя. Проверено: пустая форма, email `abc`, курс `9`, группа `123`.

## CSS-приёмы

- `box-sizing: border-box`, CSS-переменные, базовая типографика, контейнер `max-width: 1100px`
- Flexbox: шапка, меню, hero-блок, сетка карточек (`flex-wrap`), строки формы, подвал
- Состояния `:hover`, `:focus-visible` (видимый фокус), `:target` (подсветка карточки при переходе из таблицы)
- Ссылка «Перейти к основному содержимому» для клавиатуры, липкая шапка + `scroll-padding-top`
- Медиазапросы: `960px` (2 карточки в ряд), `720px` (1 карточка, шапка в колонку, кнопки на всю ширину)
- Таблица прокручивается внутри своего блока — у страницы нет горизонтальной прокрутки

## Проверка

- Нет дублей `id`, все якорные ссылки ведут к существующим разделам, у всех полей есть `label`
- Нет ошибок в Console, все изображения загружаются
- Навигация клавишей Tab проходит по всем ссылкам и полям в логичном порядке
- Ширина 375 px — горизонтальной прокрутки нет
